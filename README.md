# React Forms Practice

This project is a simple practice application built while learning the **React Forms** module.  
It demonstrates how to work with controlled inputs using React state.

## 🚀 Concepts Covered
- Controlled components in React
- Managing form input using `useState`
- Handling `onChange` events
- Updating UI dynamically from state
- Understanding why `value` is required for form inputs
- Separating input handling from submit logic

## 🧠 What I Learned
- React should be the single source of truth for form data
- Inputs must use `value={state}` to stay in sync with React
- Event handlers must match the element type (input vs button)
- Clicking a button does not provide `event.target.value`
- `event.preventDefault` should be used for controlling page refresh

## 🛠️ Tech Stack
- React
- JavaScript (ES6)
- JSX
