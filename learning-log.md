### React Forms & Controlled Inputs

Completed:
- Learned how forms work in React using controlled components
- Used `useState` to store and manage input field values
- Connected input fields to state using the `value` attribute
- Handled user input with `onChange` events
- Understood the difference between input events and button click events
- Avoided common mistakes like reading `event.target.value` from non-input elements
- Built a simple form that updates UI dynamically as the user types

Key Takeaway:
In React, form inputs should be controlled by state. The input’s value must come from state, and any change should update that state to keep the UI predictable and in sync.
